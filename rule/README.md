# CSS 规则（At-Rules）

CSS 规则（At-Rules）是 CSS 中以 `@` 符号开头的特殊规则，用于定义样式表的元数据、条件规则、动画、页面布局等。

## 目录结构

- [`@charset`](./charset.md) - 定义字符编码
- [`@document`](./document.md) - 定义文档条件规则
- [`@font-face`](./font-face.md) - 定义自定义字体
- [`@import`](./import.md) - 导入其他样式表
- [`@keyframes`](./keyframes.md) - 定义动画关键帧
- [`@media`](./media.md) - 定义媒体查询
- [`@namespace`](./namespace.md) - 定义命名空间
- [`@page`](./page.md) - 定义打印页面样式
- [`@supports`](./supports.md) - 定义特性检测

## 规则分类

### 字符编码规则

- [`@charset`](./charset.md) - 定义样式表的字符编码

### 条件规则

- [`@document`](./document.md) - 根据文档条件应用样式
- [`@media`](./media.md) - 根据媒体特性应用样式
- [`@supports`](./supports.md) - 根据浏览器支持应用样式

### 字体规则

- [`@font-face`](./font-face.md) - 定义自定义字体

### 导入规则

- [`@import`](./import.md) - 导入其他样式表

### 动画规则

- [`@keyframes`](./keyframes.md) - 定义动画关键帧

### 命名空间规则

- [`@namespace`](./namespace.md) - 定义 XML 命名空间

### 页面规则

- [`@page`](./page.md) - 定义打印页面样式
