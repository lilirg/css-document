# revert

revert 关键字表示回退到上一层级的值。

## 示例

```css
/* 回退到上一层级 */
.element {
  color: revert;
}

/* 回退边框 */
.element {
  border: revert;
}

/* 回退字体大小 */
.element {
  font-size: revert;
}
```
