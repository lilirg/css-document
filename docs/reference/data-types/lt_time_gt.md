# `time`

`time` 数据类型表示时间值。

## 单位

- `s` - �?
- `ms` - 毫秒

## 示例

```css
/* animation-duration */
.animation {
  animation-duration: 0.5s;
  animation-duration: 500ms;
}

/* transition-duration */
.transition {
  transition-duration: 1s;
  transition-duration: 300ms;
}

/* animation-delay */
.animation {
  animation-delay: 0.2s;
  animation-delay: 200ms;
}

/* transition-delay */
.transition {
  transition-delay: 1s;
  transition-delay: 500ms;
}
```
