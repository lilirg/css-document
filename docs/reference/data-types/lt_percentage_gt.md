# `percentage`

`percentage` 数据类型表示百分比值。

## 示例

```css
/* 宽度 */
.element {
  width: 50%;
}

/* 高度 */
.element {
  height: 80%;
}

/* margin/padding */
.element {
  margin: 10%;
  padding: 5%;
}

/* transform */
.element {
  transform: translateX(50%);
}

/* background-position */
.element {
  background-position: 50% 50%;
}
```
