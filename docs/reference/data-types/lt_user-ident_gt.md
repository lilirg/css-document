# `user-ident`

`user-ident` 数据类型表示用户定义的标识符。

## 示例

```css
/* animation-name */
.animation {
  animation-name: myAnimation;
}

/* counter-name */
.element {
  counter-increment: myCounter;
}

/* grid-template-areas */
.grid {
  grid-template-areas: "header header"
                       "nav main"
                       "footer footer";
}
```
