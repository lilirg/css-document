# `integer`

`integer` 数据类型表示整数值。

## 示例

```css
/* z-index */
.element {
  z-index: 10;
}

/* animation-iteration-count */
.animation {
  animation-iteration-count: 3;
}

/* grid-column */
.grid {
  grid-column: 2;
}

/* nth-child */
.element:nth-child(2n) {
  background: #f0f0f0;
}
```
