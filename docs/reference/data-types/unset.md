# unset

unset 关键字表示取消设置。

## 示例

```css
/* 取消设置 */
.element {
  color: unset;
}

/* 取消设置边框 */
.element {
  border: unset;
}

/* 取消设置字体大小 */
.element {
  font-size: unset;
}
```
