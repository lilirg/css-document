# initial

initial 关键字表示属性的初始值。

## 示例

```css
/* 重置为初始值 */
.element {
  color: initial;
}

/* 重置边框 */
.element {
  border: initial;
}

/* 重置字体大小 */
.element {
  font-size: initial;
}
```
