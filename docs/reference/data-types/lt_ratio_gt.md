# `ratio`

`ratio` 数据类型表示比例值。

## 示例

```css
/* aspect-ratio */
.element {
  aspect-ratio: 16 / 9;
  aspect-ratio: 4 / 3;
  aspect-ratio: 1;
}

/* object-fit */
.element {
  object-fit: cover;
  object-fit: contain;
}
```
