# scale3d()

scale3d() 函数用于定义 3D 缩放变换。

## 语法

```css
scale3d(<sx>, <sy>, <sz>);
```

## 示例

```css
/* 3D 缩放 */
.transform {
  transform: scale3d(1.5, 1.2, 0.8);
}

/* 等比例 3D 缩放 */
.transform {
  transform: scale3d(2, 2, 2);
}
```
