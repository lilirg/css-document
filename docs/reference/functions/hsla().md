# hsla()

hsla() 函数用于定义 HSLA 颜色值（带透明度）。

## 语法

```css
hsla(<hue>, <saturation>, <lightness>, <alpha>)
```

## 示例

```css
/* 基本 HSLA 颜色 */
.color {
  color: hsla(0, 100%, 50%, 0.5);
}

/* 红色半透明 */
.color {
  color: hsla(0, 100%, 50%, 0.5);
}

/* 绿色半透明 */
.color {
  color: hsla(120, 100%, 50%, 0.8);
}

/* 蓝色半透明 */
.color {
  color: hsla(240, 100%, 50%, 0.3);
}
```
