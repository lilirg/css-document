# rotateY()

rotateY() 函数用于定义 Y 轴旋转。

## 语法

```css
rotateY(<angle>);
```

## 示例

```css
/* Y 轴旋转 */
.transform {
  transform: rotateY(45deg);
}

/* 3D 旋转 */
.transform {
  transform: rotateX(45deg) rotateY(30deg);
}
```
