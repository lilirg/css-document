# scaleX()

scaleX() 函数用于定义 X 轴缩放。

## 语法

```css
scaleX(<sx>);
```

## 示例

```css
/* 水平拉伸 */
.transform {
  transform: scaleX(1.5);
}

/* 水平压缩 */
.transform {
  transform: scaleX(0.5);
}

/* 水平翻转 */
.transform {
  transform: scaleX(-1);
}
```
