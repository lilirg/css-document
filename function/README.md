# CSS 函数 (CSS Functions)

CSS 函数用于在 CSS 中执行计算、转换和生成值。本目录包含所有 CSS 函数的详细文档。

## 目录

### 颜色函数

- [`rgb()`](rgb().md) - RGB 颜色函数
- [`rgba()`](rgba().md) - RGBA 颜色函数（带透明度）
- [`hsl()`](hsl().md) - HSL 颜色函数
- [`hsla()`](hsla().md) - HSLA 颜色函数（带透明度）

### 渐变函数

- [`linear-gradient()`](linear-gradient().md) - 线性渐变
- [`radial-gradient()`](radial-gradient().md) - 径向渐变
- [`repeating-linear-gradient()`](repeating-linear-gradient().md) - 重复线性渐变
- [`repeating-radial-gradient()`](repeating-radial-gradient().md) - 重复径向渐变

### 形状函数

- [`circle()`](circle().md) - 圆形
- [`ellipse()`](ellipse().md) - 椭圆
- [`inset()`](inset().md) - 矩形
- [`polygon()`](polygon().md) - 多边形

### 变换函数

- [`translate()`](translate().md) - 2D 平移
- [`translateX()`](translateX().md) - X 轴平移
- [`translateY()`](translateY().md) - Y 轴平移
- [`translateZ()`](translateZ().md) - Z 轴平移
- [`translate3d()`](translate3d().md) - 3D 平移
- [`scale()`](scale().md) - 2D 缩放
- [`scaleX()`](scaleX().md) - X 轴缩放
- [`scaleY()`](scaleY().md) - Y 轴缩放
- [`scaleZ()`](scaleZ().md) - Z 轴缩放
- [`scale3d()`](scale3d().md) - 3D 缩放
- [`rotate()`](rotate().md) - 2D 旋转
- [`rotateX()`](rotateX().md) - X 轴旋转
- [`rotateY()`](rotateY().md) - Y 轴旋转
- [`rotateZ()`](rotateZ().md) - Z 轴旋转
- [`rotate3d()`](rotate3d().md) - 3D 旋转
- [`skew()`](skew().md) - 2D 倾斜
- [`skewX()`](skewX().md) - X 轴倾斜
- [`skewY()`](skewY().md) - Y 轴倾斜
- [`matrix()`](matrix().md) - 2D 变换矩阵
- [`matrix3d()`](matrix3d().md) - 3D 变换矩阵

### 计算函数

- [`calc()`](calc().md) - 计算表达式
- [`attr()`](attr().md) - 属性值函数
