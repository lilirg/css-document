# CSS 数据类型 (CSS Data Types)

CSS 数据类型定义了 CSS 属性可以接受的值的类型。本目录包含所有 CSS 数据类型的详细文档。

## 目录

### 关键字

- [`inherit`](inherit.md) - 从父元素继承值
- [`initial`](initial.md) - 设置为属性的初始值
- [`revert`](revert.md) - 回退到浏览器样式表的值
- [`unset`](unset.md) - 重置为自然值（继承或初始）

### 基础类型

- [`angle`](lt_angle_gt.md) - 角度值（deg, rad, grad, turn）
- [`color`](lt_color_gt.md) - 颜色值（关键字、十六进制、RGB、HSL 等）
- [`frequency`](lt_frequency_gt.md) - 频率值（Hz, kHz）
- [`integer`](lt_integer_gt.md) - 整数值
- [`length`](lt_length_gt.md) - 长度值（px, em, rem, % 等）
- [`number`](lt_number_gt.md) - 数值（整数或小数）
- [`percentage`](lt_percentage_gt.md) - 百分比值
- [`ratio`](lt_ratio_gt.md) - 宽高比值
- [`resolution`](lt_resolution_gt.md) - 分辨率值（dppx, dpi, dpcm）
- [`string`](lt_string_gt.md) - 字符串值
- [`time`](lt_time_gt.md) - 时间值（s, ms）
- [`url`](lt_url_gt.md) - URL 值

### 高级类型

- [`basic-shape`](lt_basic-shape_gt.md) - 基本形状（inset, circle, ellipse, polygon）
- [`blend-mode`](lt_blend-mode_gt.md) - 混合模式
- [`gradient`](lt_gradient_gt.md) - 渐变（linear, radial, conic）
- [`image`](lt_image_gt.md) - 图像值（url, gradient, image-set）
- [`timing-function`](lt_timing-function_gt.md) - 时间函数（ease, cubic-bezier, steps）
- [`user-ident`](lt_user-ident_gt.md) - 用户标识符（自定义属性）
