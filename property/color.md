# color

该属性用于设置元素文本的前景色。

## 语法

```css
color: value
```

| 语法特性 | 说明 |
| :--- | :--- |
| 初始值 | `#000` (黑色) |
| 适用 HTML 元素 | 所有元素 |
| 动画 | 是（可动画） |

## 值

### 颜色值
接受任何有效的 CSS 颜色值：
- 颜色关键字（如 `red`, `blue`, `transparent`）
- 十六进制颜色（如 `#ff0000`, `#f00`）
- RGB/RGBA（如 `rgb(255, 0, 0)`, `rgba(255, 0, 0, 0.5)`）
- HSL/HSLA（如 `hsl(0, 100%, 50%)`, `hsla(0, 100%, 50%, 0.5)`）
- `currentColor`（继承自元素的 `color` 属性）
- `inherit`（从父元素继承）
- `initial`（使用初始值）
- `unset`（重置为默认值）

## 注意
- `color` 属性只影响文本颜色，不影响背景颜色
- 使用 `background-color` 设置背景颜色
- 颜色值不区分大小写（如 `Red` 和 `red` 相同）
- 透明度颜色（如 `rgba`, `hsla`）可以创建半透明文本效果

## 示例

```css
/* 基本用法 */
p {
  color: red;
}

/* 使用十六进制颜色 */
h1 {
  color: #336699;
}

/* 使用 RGB 颜色 */
span {
  color: rgb(0, 128, 0);
}

/* 使用半透明颜色 */
em {
  color: rgba(0, 0, 255, 0.5);
}

/* 使用 HSL 颜色 */
strong {
  color: hsl(120, 100%, 25%);
}
```

```html
<!-- HTML 示例 -->
<p>这段文字是红色的</p>
<h1>这个标题是深蓝色</h1>
<span>这段文字是绿色的</span>
<em>这段文字是半透明的蓝色</em>
<strong>这段文字是深绿色</strong>
```

## 使用场景

```css
/* 1. 设置段落文本颜色 */
p {
  color: #333; /* 深灰色，适合正文阅读 */
}

/* 2. 设置链接颜色 */
a {
  color: #0066cc; /* 蓝色链接 */
}
a:hover {
  color: #004499; /* 悬停时变深 */
}

/* 3. 设置错误提示颜色 */
.error {
  color: #d32f2f; /* 红色错误提示 */
}

/* 4. 设置成功提示颜色 */
.success {
  color: #388e3c; /* 绿色成功提示 */
}

/* 5. 设置警告提示颜色 */
.warning {
  color: #f57c00; /* 橙色警告提示 */
}
