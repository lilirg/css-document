# 开发者工具

浏览器开发者工具是调试 CSS 的重要工具。

## Chrome 开发者工具

### 元素面板

- 查看和编辑 HTML 元素
- 查看和编辑 CSS 样式
- 查看盒模型

### 计算面板

- 查看元素的计算样式
- 查看样式来源

### 性能面板

- 分析页面性能
- 分析渲染性能

### 颜色选择器

- 查看颜色值
- 调整颜色值

## Firefox 开发者工具

### 探查器

- 查看 CSS 选择器性能
- 查看布局性能

### CSS 检查器

- 查看和编辑 CSS 样式
- 查看盒模型

## Safari 开发者工具

### Web 检查器

- 查看和编辑 CSS 样式
- 查看盒模型
