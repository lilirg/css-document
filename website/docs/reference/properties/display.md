# display

display 属性设置元素的显示方式。

## 语法

```css
display: <display-value>;
```

## 常见值

### block

```css
display: block;
```

### inline

```css
display: inline;
```

### inline-block

```css
display: inline-block;
```

### flex

```css
display: flex;
```

### inline-flex

```css
display: inline-flex;
```

### grid

```css
display: grid;
```

### inline-grid

```css
display: inline-grid;
```

### none

```css
display: none;
```

### table

```css
display: table;
```

### table-row

```css
display: table-row;
```

### table-cell

```css
display: table-cell;
```

### flow-root

```css
display: flow-root;
```

### list-item

```css
display: list-item;
```

## 示例

```css
/* 块级元素 */
.block {
  display: block;
}

/* 行内元素 */
.inline {
  display: inline;
}

/* 行内块元素 */
.inline-block {
  display: inline-block;
}

/* Flexbox */
.flex {
  display: flex;
}

/* Grid */
.grid {
  display: grid;
}

/* 隐藏元素 */
.hidden {
  display: none;
}
```
