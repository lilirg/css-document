# `url`

`url` 数据类型表示 URL 值。

## 示例

```css
/* background-image */
.element {
  background-image: url('image.png');
}

/* cursor */
.element {
  cursor: url('cursor.png'), auto;
}

/* font-face */
@font-face {
  font-family: 'MyFont';
  src: url('font.woff2');
}

/* list-style-image */
.element {
  list-style-image: url('bullet.png');
}
```
