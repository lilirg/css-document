# inherit

inherit 关键字表示继承父元素的值。

## 示例

```css
/* 继承颜色 */
.element {
  color: inherit;
}

/* 继承字体大小 */
.element {
  font-size: inherit;
}

/* 继承边框 */
.element {
  border: inherit;
}
```
