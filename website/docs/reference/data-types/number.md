# number

number 数据类型表示数值（可以是整数或小数）。

## 示例

```css
/* z-index */
.element {
  z-index: 10;
}

/* opacity */
.element {
  opacity: 0.5;
}

/* animation-duration */
.animation {
  animation-duration: 0.5s;
}

/* nth-child */
.element:nth-child(2n) {
  background: #f0f0f0;
}

/* calc() */
.element {
  width: calc(100% / 3);
}
```
