# rotateX()

rotateX() 函数用于定义 X 轴旋转。

## 语法

```css
rotateX(<angle>);
```

## 示例

```css
/* X 轴旋转 */
.transform {
  transform: rotateX(45deg);
}

/* 3D 旋转 */
.transform {
  transform: rotateX(45deg) rotateY(30deg);
}
```
