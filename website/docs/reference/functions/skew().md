# skew()

skew() 函数用于定义 2D 倾斜变换。

## 语法

```css
skew(<ax>, <ay>?);
```

## 示例

```css
/* X 轴倾斜 */
.transform {
  transform: skew(30deg);
}

/* 双轴倾斜 */
.transform {
  transform: skew(30deg, 20deg);
}
```
