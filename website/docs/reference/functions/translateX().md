# translateX()

translateX() 函数用于定义 X 轴平移。

## 语法

```css
translateX(<tx>);
```

## 示例

```css
/* 水平平移 */
.transform {
  transform: translateX(50px);
}

/* 百分比平移 */
.transform {
  transform: translateX(50%);
}
```
