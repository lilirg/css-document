# rotateZ()

rotateZ() 函数用于定义 Z 轴旋转。

## 语法

```css
rotateZ(<angle>);
```

## 示例

```css
/* Z 轴旋转 */
.transform {
  transform: rotateZ(45deg);
}

/* 等同于 rotate() */
.transform {
  transform: rotate(45deg);
}
```
