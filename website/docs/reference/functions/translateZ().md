# translateZ()

translateZ() 函数用于定义 Z 轴平移。

## 语法

```css
translateZ(<tz>);
```

## 示例

```css
/* Z 轴平移 */
.transform {
  transform: translateZ(100px);
}

/* 3D 变换 */
.transform {
  transform: translate3d(50px, 30px, 100px);
}
```
