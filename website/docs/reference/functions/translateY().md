# translateY()

translateY() 函数用于定义 Y 轴平移。

## 语法

```css
translateY(<ty>);
```

## 示例

```css
/* 垂直平移 */
.transform {
  transform: translateY(30px);
}

/* 百分比平移 */
.transform {
  transform: translateY(25%);
}
```
