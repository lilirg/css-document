# scaleZ()

scaleZ() 函数用于定义 Z 轴缩放。

## 语法

```css
scaleZ(<sz>);
```

## 示例

```css
/* Z 轴缩放 */
.transform {
  transform: scaleZ(1.5);
}

/* 3D 缩放 */
.transform {
  transform: scale3d(1.5, 1.5, 1.5);
}
```
