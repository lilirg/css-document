# rotate()

rotate() 函数用于定义 2D 旋转。

## 语法

```css
rotate(<angle>);
```

## 示例

```css
/* 顺时针旋转 45 度 */
.transform {
  transform: rotate(45deg);
}

/* 逆时针旋转 30 度 */
.transform {
  transform: rotate(-30deg);
}

/* 半圈旋转 */
.transform {
  transform: rotate(180deg);
}
```
