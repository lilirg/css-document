# scaleY()

scaleY() 函数用于定义 Y 轴缩放。

## 语法

```css
scaleY(<sy>);
```

## 示例

```css
/* 垂直拉伸 */
.transform {
  transform: scaleY(1.5);
}

/* 垂直压缩 */
.transform {
  transform: scaleY(0.5);
}

/* 垂直翻转 */
.transform {
  transform: scaleY(-1);
}
```
